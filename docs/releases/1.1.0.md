# Daychime 1.1.0

## What's new

- Redesigned Small, Medium and Large widgets with clearer workday status and progress.
- Widget customization for workday length, time format and optional auto clock-in.
- Native Windows time pickers for start-time edits and auto clock-in settings. The picker's presentation follows Windows settings; the widget display retains its own 12/24-hour preference.
- Safer overnight editing: changing a start time preserves the displayed shift date, rejects future/nonexistent times and invalidates outdated notification actions.
- Improved auto clock-in recovery from available Windows activity records, plus sign-in/unlock background triggers to reduce dependence on opening the Widgets Board.
- Timezone-conversion hints and updated English, Traditional Chinese and Simplified Chinese text.

Requires Windows 11 (build 22000 or later) and a working, updated Widgets host. Windows controls background execution and notification delivery; auto clock-in remains best effort. If no eligible activity is available, record the start time manually.
